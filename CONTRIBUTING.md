# Contributing

Keep installation no-code, verify every Shopify HMAC, preserve webhook and GOVP
idempotency, and minimize order data. Never log access tokens, connector tokens or
customer payloads.

1. Open an issue for large behavioral changes.
2. Run `npm ci` and `npm run check`.
3. Run `npm run validate:shopify` when changing app configuration.
4. Describe webhook, scope and privacy impact in the pull request.
5. Update `CHANGELOG.md` for user-visible changes.

Contributions are accepted under Apache-2.0.
