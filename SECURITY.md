# Security policy

Do not disclose vulnerabilities through public issues. Use GitHub private
vulnerability reporting or email `research@gemacode.org` with affected versions,
impact and synthetic reproduction steps. Never include app secrets, tokens or real
webhook payloads. Reports are acknowledged within five business days.

Rotate `SHOPIFY_API_SECRET`, `TOKEN_ENCRYPTION_KEY` and affected connector tokens
when exposure is suspected; encryption-key rotation requires a migration plan.
